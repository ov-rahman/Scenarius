# Сценариус

Редактор нелинейного сюжета для игры. Письмо текстом и просмотр структуры —
два режима одного и того же сценария, а не два разных инструмента.

## Как открыть

**Свой адрес через GitHub Pages.** В репозитории лежит рабочий процесс
`.github/workflows/pages.yml`: каждый push в `main` собирает приложение и
публикует его. Один раз нужно включить Pages вручную — Settings → Pages →
Source: **GitHub Actions**. После этого адрес вида
`https://<логин>.github.io/Scenarius/` обновляется сам.

**Одним файлом.** `pnpm bundle` собирает приложение в единственный
самодостаточный HTML без внешних запросов — его можно открыть с диска или
положить куда угодно.

**Локально.** Нужен Node 22 и pnpm:

```bash
cd app
pnpm install
pnpm dev
```

## Что умеет

- **Лента письма.** Сцены текущего маршрута склеены в одну полосу. На развилке
  лента без разрыва идёт по выбранной ветке, рядом переключатель.
- **Структура.** Тот же сценарий схемой: развилки, схождения, подсветка
  активного пути, фильтры по сюжетной линии, незакрытым заделам и концовкам.
- **Факты.** Ключевые моменты, знания персонажей и заделы — одна сущность с
  тремя лицами. Задел закрывается сам, когда привязан узел-отыгрыша.
- **Условия.** Ветка открывается или блокируется набором фактов; тем же способом
  кусок текста внутри сцены становится условным.
- **Персонажи.** Упоминание через `@`, карточка с характером и знаниями,
  актуальными именно в этом месте сюжета.
- **Телефон.** Одна колонка, нижняя навигация, панель шторкой снизу. Писать
  можно всё то же; не таскаются только узлы графа.
- **Темы, автосохранение, экспорт и импорт проекта в JSON.**

Решения, на которых всё построено, и границы первой версии — в
[docs/DESIGN.md](docs/DESIGN.md).

## Где живёт текст

Локально, в браузере (IndexedDB). Синхронизация через GitHub отложена на второй
этап, поэтому **проекты не переезжают между устройствами**, а очистка данных
браузера стирает сценарий. Пока синка нет, выгружай копию через экспорт.

## Проверки

```bash
cd app
pnpm smoke
```

Гоняет настоящий Chromium через создание проекта, письмо, развилки, факты,
условия, персонажей и мобильную раскладку — сорок семь проверок, включая
геометрию на экране телефона.
