# Сценариус — принятые решения

Редактор нелинейного сюжета для игры. Документ фиксирует решения, принятые до
написания кода, и границы первой версии.

## Архитектура сюжета

**Первичны узлы-сцены, а не сплошной документ.** Текст линеен, граф — нет;
развилка на три ветки не имеет естественного вида в простыне. Узел — законченный
кусок на 1–3 экрана текста, поэтому 300 сцен остаются читаемым графом.

**Активный путь.** У редактора есть текущий маршрут через граф: стартовый узел
плюс выбор ветки на каждой развилке. Режим письма — склейка сцен вдоль этого
маршрута в одну ленту; на развилке лента без разрыва идёт по выбранной ветке, на
стыке — переключатель «1/3». Маршрут можно сохранить под именем («пацифист»).

**Граф ациклический.** Сюжетные связи ведут только вперёд. Возвраты в
пройденные сцены выражаются мягкими связями: рисуются пунктиром как напоминание,
в расчёте пути и фактов не участвуют. Это позволяет считать порядок сцен и
расклад фактов однозначно, без флагов состояния и без движка.

**Сюжетные линии образуют дерево.** Второстепенная линия не противопоставлена
основной, а исходит из неё: у линии есть родитель, корневая линия и есть
основная. Второстепенная может ветвиться дальше. Глубина задаёт визуальный вес —
корневая рисуется толстой и яркой, каждый следующий уровень тоньше и приглушённее
(различать глубже третьего уровня на глаз всё равно нельзя, там вес упирается).
Вместо переключателя «основная ↔ второстепенная» линию переподчиняют другой;
попытка подчинить линию собственной ветви отсекается, чтобы не получить цикл.

**Единый примитив — факт.** Ключевой момент (игрок что-то сделал), знание
персонажа (кто-то что-то узнал) и задел (заявка, ждущая отыгрыша) устроены
одинаково: «нечто, случающееся в узле и действующее дальше по пути». Внутри —
одна сущность `Fact` с полем `face`, снаружи — три панели с разными названиями.
Отсюда бесплатно получаются условия вида «если персонаж знает, что…» и
автозакрытие задела при привязке узла-отыгрыша.

**Расклад фактов вытекает из активного пути.** Ручных тумблеров нет: выбрал
ветку — текст и доступность веток ниже перестроились. Невозможных сочетаний
(«пощадил и убил одновременно») не бывает по построению.

**Условие — единственный вид логики.** Набор фактов «все из» и «ни одного из»,
без чисел, счётчиков и вложенности. Применяется в двух местах: к связи
(доступна ли ветка) и к блоку текста внутри сцены (виден ли абзац).

## Интерфейс

- Новая сцена и развилка создаются плюсиком между блоками; на ПК то же самое
  доступно с клавиатуры.
- ПК: навигация слева, лента в центре, контекстная панель справа; панели
  сворачиваются.
- Телефон: пишешь полноценно, граф смотришь и навигируешь, но не перестраиваешь —
  раскладка связей пальцем в первую версию не входит.
- Светлая тема по умолчанию, тёмная переключателем, выбор сохраняется.
- Автосохранение, кнопки «Сохранить» нет.

## Данные

- Локально: IndexedDB через Dexie. Экспорт и импорт проекта в JSON.
- Офлайн после первой загрузки.
- Синхронизация через GitHub — второй этап. Модель заложена под неё: у записей
  есть `updatedAt`, у проекта — `schemaVersion`.
- Пока синхронизации нет, приложение напоминает выгрузить копию: IndexedDB
  чистится браузером, и молчать об этом нечестно.

## Стек

- **React + TypeScript + Vite.** Под React есть Tiptap, а условный блок текста
  проще всего сделать расширением ProseMirror, а не борьбой с contenteditable.
  React Native оставляет открытым путь в мобильное приложение.
- **Tiptap** — редактор сцены и место, где живут условные блоки и упоминания `@`.
- **Dexie** — обёртка над IndexedDB.
- **Zustand** — состояние без церемоний.
- **@xyflow/react + dagre** — граф с автораскладкой и ручным сдвигом узлов.
- **CSS-переменные** — темы переключаются без перерисовки дерева.

## Границы первой версии

Входит: узлы-сцены, лента с активным путём, граф с развилками и схождениями,
дерево сюжетных линий с цветом и переподчинением, факты во всех трёх лицах,
условия на связях, условный текст внутри сцены, персонажи с карточкой по `@`,
заделы, темы, письмо на телефоне, локальное хранение с экспортом.

Отложено осознанно:

- числовые условия и счётчики — «геноцид по числу убийств» так не выражается;
- синхронизация через GitHub;
- редактирование графа пальцем на телефоне;
- совместная работа.
